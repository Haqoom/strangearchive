# StrangeArchive Uploader

A private upload tool for the YouTube channel [기묘한 서고 (@StrangeArchiveK)](https://www.youtube.com/@StrangeArchiveK).

It uploads the channel owner's own Shorts videos to the channel using the YouTube Data API.
