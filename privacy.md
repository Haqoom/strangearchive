# Privacy Policy - StrangeArchive Uploader

Last updated: 2026-11-15

StrangeArchive Uploader is a private tool used only by the owner of the YouTube channel "StrangeArchive" (@StrangeArchiveK) to upload the owner's own videos to that channel.

## Data accessed

- The tool uses the YouTube Data API to upload videos, set video titles, descriptions and tags, and add videos to the channel's own playlists.
- It reads only the basic information of the signed-in channel to confirm that the correct channel is used.

## Data storage

- The OAuth sign-in token is stored only on the owner's own computer.
- No data is sent to, stored on, or shared with any other server or third party.

## Data sharing

- No user data is sold, shared, or used for advertising.

## Revoking access

- Access can be removed at any time at <https://myaccount.google.com/permissions>.

## Contact

- Via the YouTube channel <https://www.youtube.com/@StrangeArchiveK>
